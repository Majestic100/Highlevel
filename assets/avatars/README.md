# Trust pill avatars

Drop the 4 artist photos in this folder named exactly:

- `01.jpg`
- `02.jpg`
- `03.jpg`
- `04.jpg`

Each should be a square crop (~200x200px) of a face. The page renders
them as 30px circles in the hero trust pill ("Trusted by 50+ studios
and artists across the US"). They are also hosted via GitHub Pages,
so the GHL iframe picks them up automatically once committed.
